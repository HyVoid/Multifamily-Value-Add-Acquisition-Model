## ما الذي يساعدك هذا النموذج على تتبّعه

* سعر الاستحواذ مقابل خلق القيمة المستقرة القابلة للتحقيق.
* انخفاض تسعير الإيجارات الحالية مقابل إمكانية ارتفاع الإيجار السوقي القابل للتحقيق.
* وتيرة الإنفاق على التجديدات مقابل تحقق نمو صافي الدخل التشغيلي (NOI) الفعلي.
* قيود القدرة على الاقتراض وفقًا لمعايير التحليل الاستثماري (underwriting) الخاصة بالجهات المُقرضة.
* تقلب التدفق النقدي التشغيلي الشهري خلال فترات إعادة التموضع.
* حساسية تقييم الخروج (البيع) تحت افتراضات السوق المتغيرة.

---

## لماذا بنيتُ هذا النموذج

معظم نماذج الاستحواذ على العقارات السكنية متعددة العائلات تُنتج إجابات قبل التحقق مما إذا كانت الافتراضات الأساسية قابلة للتحقيق تشغيليًا.

في الواقع، يفشل الاستحواذ لخلق القيمة (value-add) بشكل أقل بسبب معادلات خاطئة، وبشكل أكبر بسبب استدلال غير صحيح.

تشمل أكثر حالات الفشل التحليلي شيوعًا:

* افتراض أن جميع الوحدات يمكنها تحقيق الإيجار السوقي فورًا،
* تحديد حجم الدين بناءً على نسبة القرض إلى القيمة (LTV) فقط مع تجاهل قيود التدفق النقدي لدى المُقرض،
* التعامل مع تنفيذ التجديدات كما لو كان لحظيًا،
* تقييم عمليات الخروج (البيع) باستخدام صافي الدخل التشغيلي (NOI) اللاحق بدلًا من المتوقع،
* افتراض حدوث تحسينات تشغيلية دون احتكاك زمني.

بنيتُ هذا النموذج بعد أن لاحظتُ مرارًا وتكرارًا حالات وافقت فيها لجان الاستثمار على عمليات استحواذ استنادًا إلى افتراضات متناقضة داخليًا وكان من الصعب اكتشافها داخل جداول التحليل الاستثماري (underwriting) التقليدية.

فلننظر في مثال مبسّط:

|                        | النموذج التقليدي |                   هذا النموذج |
| ---------------------- | ----------------: | ---------------------------: |
| سعر الشراء         |            $18.0M |                       $18.0M |
| العائد الداخلي المُرَوَّح (Levered IRR) المتوقع  |             19.2% |                        12.8% |
| افتراض نمو الإيجار |         فوري |                 مُدفوع بالعقود الإيجارية |
| تحديد حجم الدين            |           75% LTV | تحليل استثماري (underwriting) بأربعة قيود |
| فترة التجديد      |           لحظي |              طرح على مدى 24 شهرًا |
| تقييم الخروج         |      صافي الدخل التشغيلي (NOI) اللاحق |                  صافي الدخل التشغيلي (NOI) المتوقع |

لم يتغيّر الاستثمار نفسه.

تغيّرت فقط جودة الإطار التحليلي.

يعمل هذا المصنف (workbook) إذًا كنظام استدلال مُنتَج تجاريًا وليس كنموذج مالي تقليدي. وغايته ليست مجرد حساب العوائد، بل كشف الافتراضات التي تحدد ما إذا كانت تلك العوائد قابلة للتحقيق.

| ----------------------------------- | ----------------------------------------- | ------------------------------------------------------- |
| تجاهل توقيت تجديد العقود الإيجارية       | يبدو نمو الإيجار فوريًا             | يتبع إطلاق الإيجار انتهاء العقود الفعلية           |

## لمن صُمم هذا النموذج

صُممت هذه الأداة من أجل:

* محللي الاستحواذ على العقارات السكنية متعددة العائلات.
* الرعاة المستقلون.
* فرق الأسهم الخاصة العقارية.
* مُجمّعو الشقق (apartment syndicators).
* شركات الاستثمار الصغيرة والمتوسطة.
* مُنمذجو النماذج المالية الذين يجرون التحليل الاستثماري (underwriting) لصفقات خلق القيمة (value-add).

لم تُصمم هذه الأداة من أجل:

* عمليات إدارة الأملاك.
* أنظمة المحاسبة للمؤسسات الكبيرة.
* منصات إدارة الإنشاءات.
* برمجيات إدارة المحافظ.
* مشاريع استبدال نظام تخطيط موارد المؤسسة (ERP).

لا يُشترط أي خبرة في جداول البيانات. افتح النسخة المخصصة للمتصفح وابدأ التحليل الاستثماري (underwriting) فورًا، أو استخدم نسخة Excel للتدقيق الكامل والتخصيص ومسارات المراجعة المؤسسية.

## نبذة

أبني أدوات تحليلية خفيفة للمواقف التي يوجد فيها أجزاء متحركة كثيرة جدًا بحيث يتعذر إدارتها بثقة عبر الحدس وحده.

السؤال الكامن وراء كل أداة واضح وبسيط:

> **ما المعلومات التي ينبغي أن توجد في مكان واحد لاتخاذ القرار التالي بثقة؟**

يُمثل نموذج الاستحواذ هذا على العقارات السكنية متعددة العائلات مثالًا على ذلك النهج: تحويل ممارسات التحليل الاستثماري (underwriting) المؤسسية إلى إطار عمل قابل لإعادة الاستخدام لدعم القرار يظل شفافًا وقابلًا للتدقيق وعمليًا من الناحية التشغيلية.

### بنية المصنف (Workbook Architecture)

يتبع المصنف (workbook) بنية نمذجة صارمة من ثلاث طبقات تفصل بين الافتراضات والحسابات ومخرجات القرار.

```text
INPUT LAYER
│
├── Sheet 1   Control Panel
├── Sheet 2   Rent Roll Input
└── Sheet 3   Operations Assumptions
              │
              ▼
CALCULATION LAYER
│
├── Sheet 4   Renovation Schedule
├── Sheet 5   Debt Sizing Engine
├── Sheet 6   Monthly Cash Flow Engine
└── Sheet 7   Exit Valuation
              │
              ▼
OUTPUT LAYER
│
├── Sheet 8   Equity Returns
└── Sheet 9   Dashboard
```

| الورقة (Sheet)          | الوظيفة                                      |
| -------------- | --------------------------------------------- |
| Control Panel  | افتراضات الاستحواذ ومعلمات السوق |
| Rent Roll      | خط أساس العقود الإيجارية والإيجارات على مستوى الوحدة (سجل الإيجارات rent roll)            |
| Operations     | الشواغر (vacancy) والمصروفات وافتراضات التشغيل  |
| Renovation     | جدول تنفيذ خلق القيمة (value-add)                  |
| Debt Engine    | قيود التحليل الاستثماري (underwriting) المؤسسية        |
| Cash Flow      | توقعات التشغيل والتمويل الشهرية     |
| Exit           | تحليل تقييم التصرف (البيع)                 |
| Equity Returns | حسابات عوائد المستثمر                  |
| Dashboard      | تصوّر دعم القرار                |

### ثلاث فخاخ يقع فيها حتى مستثمرو العقارات السكنية متعددة العائلات ذوو الخبرة

#### الفخ الأول: الإيجار السوقي ليس إيجارًا قابلًا للتحقيق

تمت الموافقة على استحواذ لخلق القيمة (value-add) لأن دراسات السوق أشارت إلى إمكانية ارتفاع الإيجار بنسبة 28%.

ومع ذلك، أخّرت بنية العقود الإيجارية القائمة تحقق ذلك الارتفاع قرابة عامين.

| الافتراض               | النموذج الأصلي | النموذج المصحح |
| ------------------------ | -------------: | --------------: |
| الوحدات                    |            120 |             120 |
| التسعير الفوري حسب السوق |            نعم |              لا |
| متوسط المدة المتبقية للعقد  |        مُتجاهَلة |       14 شهرًا |
| العائد الداخلي المُرَوَّح (Levered IRR)              |          20.8% |           13.9% |

يحدث الخطأ التحليلي لأن الإيجار السوقي والإيجار القابل للتحقيق ليسا متغيرين متكافئين.

النهج الصحيح هو النمذجة وفقًا لما يلي:

* جداول انتهاء العقود الإيجارية،
* توقيت إطلاق الفجوة بين السوق والعقد (loss-to-lease)،
* فترات التوقف أثناء التجديدات،
* الاستقرار بعد التجديدات.

<details>
<summary>منطق المعادلة</summary>

```excel
Loss_to_Lease =
Current_Market_Rent
-
Current_Actual_Rent

Released according to:
Lease_End_Month
```

</details>

---

#### الفخ الثاني: نسبة القرض إلى القيمة (LTV) لا تحدد القدرة على الاقتراض

افترض أحد الرعاة توفر التمويل بنسبة 75% من نسبة القرض إلى القيمة (LTV).

وافق المُقرض في النهاية على التمويل بناءً على قيود العائد على الدين (Debt Yield).

| القيد | الحد الأقصى للقرض |
| ---------- | -----------: |
| LTV        |       $15.0M |
| LTC        |       $14.2M |
| DSCR       |       $12.7M |
| Debt Yield |       $11.8M |

مبلغ القرض النهائي:

```text
$11.8M
```

يحدث الفشل التحليلي لأن المُقرضين يقيّمون قيود مخاطر متعددة بشكل متزامن.

النهج الصحيح هو تطبيق الحد الأدنى للقرض المدعوم عبر جميع مقاييس التحليل الاستثماري (underwriting).

<details>
<summary>منطق المعادلة</summary>

```excel
Final_Loan_Amount =
MIN(
LTV_Sized_Loan,
LTC_Sized_Loan,
DSCR_Sized_Loan,
Debt_Yield_Sized_Loan
)
```

</details>

---

#### الفخ الثالث: قيم الخروج تعتمد على الدخل المستقبلي

حسب نموذج للتحليل الاستثماري (underwriting) حصائل الخروج باستخدام صافي الدخل التشغيلي (NOI) اللاحق للسنة الخامسة.

قيّم المشترون المؤسسيون الأصل باستخدام الدخل المستقر المتوقع.

| الطريقة       | قيمة الخروج |
| ------------ | ---------: |
| صافي الدخل التشغيلي (NOI) اللاحق |     $33.1M |
| صافي الدخل التشغيلي (NOI) المتوقع  |     $28.4M |

قلّص هذا الفارق العوائد المتوقعة لحقوق الملكية بأكثر من 400 نقطة أساس.

يحدث الفشل التحليلي لأن تسعير الأصل يعكس الدخل المستقبلي المتوقع بدلًا من الدخل التاريخي.

تُرسمل المنهجية المصححة إسقاطات صافي الدخل التشغيلي (NOI) المتوقع لاثني عشر شهرًا.

<details>
<summary>منطق المعادلة</summary>

```excel
Gross_Sale_Value =
Forward_12M_NOI
/
Exit_Cap_Rate
```

</details>

### سيناريو توضيحي

فلننظر في استحواذ لخلق القيمة (value-add) على 96 وحدة.

#### الاستحواذ

| المدخل             |       القيمة |
| ----------------- | ----------: |
| سعر الشراء    | $18,000,000 |
| تكاليف الإغلاق     |        2.0% |
| ميزانية التجديد |  $1,920,000 |
| فترة الاحتفاظ       |     5 سنوات |
| معدل الرسملة (cap rate) عند الخروج     |       5.75% |

#### التشغيل

| المدخل                |  القيمة |
| -------------------- | -----: |

| علاوة التجديد   |   $225 |
| الشواغر (vacancy)              |   5.0% |
| الديون المعدومة             |   1.5% |

#### التمويل

| القيد | النتيجة |
| ---------- | -----: |
| LTV        | $13.5M |
| LTC        | $14.1M |
| DSCR       | $12.3M |
| Debt Yield | $11.9M |

مبلغ الدين النهائي:

```text
$11.9M
```

#### نتائج الاستثمار

| المقياس               | النتيجة |
| -------------------- | -----: |
| صافي الدخل التشغيلي (NOI) للسنة الأولى           | $1.18M |
| صافي الدخل التشغيلي (NOI) المستقر       | $2.04M |
| قيمة الخروج           | $35.5M |
| العائد الداخلي المُرَوَّح (Levered IRR)          |  15.6% |
| مضاعف حقوق الملكية (Equity Multiple)      |  2.09x |
| متوسط العائد على النقد (Cash-on-Cash) |   9.4% |
| العائد على التكلفة (Yield-on-Cost)        |   9.3% |

#### تفسير القرار

يظل الاستحواذ جذابًا فقط إذا تحققت الشروط التالية:

* بقيت مدة التجديد أقل من 30 شهرًا،
* بقي معدل الرسملة (cap rate) عند الخروج أقل من 6.00%،
* تجاوزت علاوات الإيجار 175 دولارًا/وحدة/شهر،
* بقيت متطلبات العائد على الدين لدى المُقرض أقل من 9.0%.

### مرجع المعادلات

<details>
<summary>محرك تحديد حجم الدين</summary>

```excel
LTV_Loan =
Purchase_Price * Max_LTV

LTC_Loan =
Project_Cost * Max_LTC

DSCR_Loan =
PV(
Interest_Rate/12,
Amortization_Months,
NOI/DSCR/12
)

Debt_Yield_Loan =
NOI / Debt_Yield

Final_Loan =
MIN(
LTV,
LTC,
DSCR,
Debt_Yield
)
```

</details>

<details>
<summary>محرك التجديد</summary>

```excel
Cumulative_Renovated_Units =
MIN(
Total_Units,
(Timeline-Start_Month)
*
Monthly_Capacity
)
```

</details>

<details>
<summary>محرك التدفق النقدي</summary>

```excel
EGI =
Rental_Income
-
Vacancy
-
Bad_Debt
+
Other_Income

NOI =
EGI
-
Operating_Expenses
```

</details>

</details>


| ------------------ | ------------- | ------------------ |
