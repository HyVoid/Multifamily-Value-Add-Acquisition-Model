* Akquisitionspreis versus erzielbare Wertschöpfung im stabilisierten Zustand.

## Warum ich dies entwickelt habe

Die meisten Multifamily-Akquisitionsmodelle liefern Antworten, bevor geprüft wird, ob die zugrunde liegenden Annahmen operativ erreichbar sind.

In der Praxis scheitern Value-Add-Akquisitionen seltener an falschen Formeln und häufiger an falschen Überlegungen.

Die häufigsten analytischen Fehler sind:

* die Annahme, dass alle Einheiten sofort Marktmiete erzielen können,
* die Bemessung von Fremdkapital allein nach LTV unter Ignorierung von Cashflow-Beschränkungen der Kreditgeber,
* die Behandlung der Renovierungsdurchführung als augenblicklich,
* die Bewertung von Exits mit nachlaufender statt vorlaufender NOI,
* die Annahme, dass operative Verbesserungen ohne zeitliche Reibung erfolgen.  

Ich habe dieses Modell entwickelt, nachdem ich wiederholt Situationen beobachtet hatte, in denen Investitionsausschüsse Akquisitionen auf Basis intern inkonsistenter Annahmen genehmigten, die in konventionellen Underwriting-Tabellen nur schwer zu erkennen waren.

Betrachten Sie ein vereinfachtes Beispiel:

|                        | Traditionelles Modell |                   Dieses Modell |
| ---------------------- | ----------------: | ---------------------------: |
| Kaufpreis         |            $18.0M |                       $18.0M |
| Projizierte Levered IRR  |             19.2% |                        12.8% |
| Mietwachstumsannahme |         Sofort |                 Leasinggetrieben |
| Fremdkapitalbemessung            |           75% LTV | Vier-Beschränkungs-Underwriting |
| Renovierungszeitraum      |           Sofort |             24-monatiger Rollout |
| Exit-Bewertung         |      Nachlaufende NOI |                  Vorlaufende NOI |

Die Investition selbst hat sich nicht geändert.

Nur die Qualität des analytischen Frameworks hat sich geändert.

Diese Arbeitsmappe funktioniert daher als produktisiertes Analysesystem und nicht als traditionelles Finanzmodell. Ihr Zweck ist nicht bloß die Berechnung von Renditen, sondern die Offenlegung der Annahmen, die bestimmen, ob diese Renditen erreichbar sind.

### Drei Fallen, die auch erfahrene Multifamily-Investoren ereilen

#### Falle 1: Marktmiete ist nicht erzielbare Miete

Eine Value-Add-Akquisition wurde genehmigt, weil Marktumfragen ein Mietpotenzial von 28 % nahelegten.

Die bestehende Leasingstruktur verzögerte jedoch die Realisierung dieses Potenzials um fast zwei Jahre.

| Annahme               | Ursprüngliches Modell | Korrigiertes Modell |
| ------------------------ | -------------: | --------------: |
| Einheiten                    |            120 |             120 |
| Sofortige Marktanpassung |            Ja |              Nein |
| Verbleibende Durchschnitts-Leasinglaufzeit  |        Ignoriert |       14 Monate |
| Levered IRR              |          20.8% |           13.9% |

Der analytische Fehler entsteht, weil Marktmiete und realisierbare Miete keine gleichwertigen Variablen sind.

Der korrekte Ansatz ist die Modellierung von:

* Leasing-Endlaufplänen,
* Zeitpunkten der Loss-to-Lease-Freigabe,
* Renovierungs-Stillstandszeiten,
* Stabilisierung nach der Renovierung.

<details>
<summary>Formellogik</summary>

```excel
Loss_to_Lease =
Current_Market_Rent
-
Current_Actual_Rent

Released according to:
Lease_End_Month
```

</details>

---

#### Falle 2: LTV bestimmt nicht die Fremdkapitalkapazität

Ein Sponsor nahm eine Finanzierungsverfügbarkeit von 75 % LTV an.

Der Kreditgeber genehmigte die Finanzierung letztlich auf Basis von Debt-Yield-Beschränkungen.

| Beschränkung | Maximales Darlehen |
| ---------- | -----------: |
| LTV        |       $15.0M |
| LTC        |       $14.2M |
| DSCR       |       $12.7M |
| Debt Yield |       $11.8M |

Finaler Darlehensbetrag:

```text
$11.8M
```

Das analytische Versagen entsteht, weil Kreditgeber mehrere Risikobeschränkungen simultan bewerten.

Der korrekte Ansatz ist die Anwendung des minimalen unterstützten Darlehensbetrags über alle Underwriting-Kennzahlen. 

<details>
<summary>Formellogik</summary>

```excel
Final_Loan_Amount =
MIN(
LTV_Sized_Loan,
LTC_Sized_Loan,
DSCR_Sized_Loan,
Debt_Yield_Sized_Loan
)
```

</details>

---

#### Falle 3: Exit-Werte hängen vom künftigen Einkommen ab

Ein Underwriting-Modell berechnete die Exit-Erlöse mit der nachlaufenden NOI von Jahr 5.

Institutionelle Käufer bewerteten das Asset mit dem vorlaufenden stabilisierten Einkommen.

| Methode       | Exit-Wert |
| ------------ | ---------: |
| Nachlaufende NOI |     $33.1M |
| Vorlaufende NOI  |     $28.4M |

Dieser Unterschied reduzierte die projizierten Eigenkapitalrenditen um über 400 Basispunkte.

Das analytische Versagen entsteht, weil die Asset-Bepreisung erwartetes künftiges Einkommen und nicht historisches Einkommen widerspiegelt.

Die korrigierte Methodik kapitalisiert die vorlaufenden Zwölfmonats-NOI-Prognosen. 

<details>
<summary>Formellogik</summary>

```excel
Gross_Sale_Value =
Forward_12M_NOI
/
Exit_Cap_Rate
```

</details>

### Beispielszenario

Betrachten Sie eine Value-Add-Akquisition mit 96 Einheiten.

#### Akquisition

| Eingabe             |       Wert |
| ----------------- | ----------: |
| Kaufpreis    | $18,000,000 |
| Transaktionskosten     |        2.0% |
| Renovierungsbudget |  $1,920,000 |
| Halteperiode       |     5 Jahre |
| Exit-Cap-Rate     |       5.75% |

#### Betrieb

| Eingabe                |  Wert |
| -------------------- | -----: |
| Aktuelle Durchschnittsmiete | $1,250 |
| Marktmiete          | $1,520 |
| Renovierungsprämie   |   $225 |
| Leerstand              |   5.0% |
| Forderungsausfälle         |   1.5% |

#### Finanzierung

| Beschränkung | Ergebnis |
| ---------- | -----: |
| LTV        | $13.5M |
| LTC        | $14.1M |
| DSCR       | $12.3M |
| Debt Yield | $11.9M |

Finaler Fremdkapitalbetrag:

```text
$11.9M
```

#### Investitionsergebnisse

| Kennzahl               | Ergebnis |
| -------------------- | -----: |
| NOI Jahr 1           | $1.18M |
| Stabilisierte NOI       | $2.04M |
| Exit-Wert           | $35.5M |
| Levered IRR          |  15.6% |
| Eigenkapitalmultiple (Equity Multiple)      |  2.09x |
| Durchschnittliche Cash-on-Cash-Rendite |   9.4% |
| Yield-on-Cost        |   9.3% |

#### Entscheidungsinterpretation

Die Akquisition bleibt nur dann attraktiv, wenn:

* die Renovierungsdauer unter 30 Monaten bleibt,
* die Exit-Cap-Raten unter 6,00 % bleiben,
* die Mietprämien $175/Einheit/Monat übersteigen,
* die Debt-Yield-Anforderungen der Kreditgeber unter 9,0 % bleiben.

### Formelreferenz

<details>
<summary>Fremdkapitalbemessungs-Engine</summary>

```excel
LTV_Loan =
Purchase_Price * Max_LTV

LTC_Loan =
Project_Cost * Max_LTC

DSCR_Loan =
PV(
Interest_Rate/12,
Amortization_Months,
NOI/DSCR/12
)

Debt_Yield_Loan =
NOI / Debt_Yield

Final_Loan =
MIN(
LTV,
LTC,
DSCR,
Debt_Yield
)
```

</details>

<details>
<summary>Renovierungs-Engine</summary>

```excel
Cumulative_Renovated_Units =
MIN(
Total_Units,
(Timeline-Start_Month)
*
Monthly_Capacity
)
```

</details>

<details>
<summary>Cashflow-Engine</summary>

```excel
EGI =
Rental_Income
-
Vacancy
-
Bad_Debt
+
Other_Income

NOI =
EGI
-
Operating_Expenses
```

</details>

<details>
<summary>Exit-Bewertung</summary>

```excel
Exit_Value =
Forward_12M_NOI
/
Exit_Cap_Rate

Net_Sale_Proceeds =
Exit_Value
-
Selling_Costs
-
Loan_Balance
```

</details>

<details>
<summary>Eigenkapitalrenditen</summary>

```excel
Levered_IRR =
XIRR(
Levered_Cashflows,
Dates
)

MoIC =
Positive_Cashflows
/
Initial_Equity
```

</details>

### Validierungsregeln

| Feld              | Regel          | Fehlerverhalten     |
| ------------------ | ------------- | ------------------ |
| Kaufpreis     | > 0           | Harter Stopp          |
| Halteperiode        | 1–10 Jahre    | Validierungsfehler   |
| Exit-Cap-Rate      | ≥ Einstiegs-Cap   | Warnung            |
| Maximales LTV        | ≤ 75%         | Warnung            |
| Minimales DSCR       | ≥ 1.20x       | Beschränkungsfehler |
| Debt Yield         | ≥ 8.00%       | Beschränkungsfehler |
| Eigenkapitalbedarf | > 0           | Harter Stopp          |
| Monatliches DSCR       | ≥ 1.05x       | Covenant-Warnung   |
| Renovierungseinheiten   | ≤ Gesamteinheiten | Validierungsfehler   |
| NPV-Abstimmung | Exakte Übereinstimmung   | Prüfungsfehler      |

</details>
